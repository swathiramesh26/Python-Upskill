# API & UI Test Automation Suite
Pytest-based test automation covering 
- Practice UI (saucedemo.com)
- REST API testing (reqres.in)  
- End-to-end UI testing (Thinking Tester Contact List)
with JSON schema validation, Allure reporting, and a GitHub Actions CI pipeline.
What's covered
API tests — CRUD operations (GET/POST/PUT/DELETE), authentication (Bearer tokens, login), JSON schema validation, response-time assertions, and negative/error-path scenarios.
UI tests — signup, login (valid and invalid credentials), adding a contact, and logout, driven with Playwright across Chromium and Firefox.
Reporting — Allure, annotated with feature/story groupings, severity levels, and step breakdowns.
CI — GitHub Actions runs the full suite on every push/PR and publishes the Allure report as a downloadable artifact.

# Creating virtual environment
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# Install dependencies:
bash
pip install -r requirements.txt
playwright install --with-deps chromium firefox

Running the tests
bash
# Everything
pytest -v
# API tests only
pytest tests/api -v
# UI tests only
pytest tests/ui -v
# A single test, by name
pytest "tests/api/test_users.py::TestCreateUser::test_create_user" -v
# Headed browser, slowed down, for debugging UI tests
pytest tests/ui -v --headed --slowmo 200 --browser chromium

Allure reporting
bash
# Run tests and collect raw results
pytest -v --alluredir=allure-results
# Quick view (temporary local server, closes on Ctrl+C)
allure serve allure-results
# Persistent HTML copy
allure generate allure-results --clean -o allure-report
allure open allure-report

Requires the Allure commandline tool separately from the Python package:
bash
brew install allure        # macOS
# or: npm install -g allure-commandline
